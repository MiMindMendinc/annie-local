# Code of Conduct

Annie Local is built around private, local-first AI interaction. Contributors and users are expected to keep the project respectful, safe, and focused on practical improvements.

## Expected Behavior

Examples of expected behavior include:

- treating people respectfully
- giving useful technical feedback
- protecting private user data
- using synthetic examples instead of real sensitive content
- being honest about technical limits
- keeping safety and privacy concerns visible

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment, threats, or personal attacks
- publishing another person’s private information
- sharing real secrets, credentials, private logs, or emotional crisis content
- submitting examples that increase real-world harm without a clear defensive purpose
- claiming clinical, legal, security, or compliance status without evidence
- intentionally hiding network calls or remote dependencies while claiming offline operation

## Sensitive Context

Annie Local may involve local memory, voice interfaces, emotional support language, and private model routing. Keep all test examples synthetic. Do not include real user conversations, private family records, therapy notes, medical details, or crisis content in issues, pull requests, screenshots, or logs.

## Reporting Concerns

Report conduct concerns privately to:

**michiganmindmendinc@proton.me**

For security vulnerabilities, follow `SECURITY.md` instead of opening a public issue.

## Enforcement

Maintainers may edit, close, remove, or reject contributions that violate this code of conduct or create unnecessary safety, privacy, legal, or reputational risk for the project.
